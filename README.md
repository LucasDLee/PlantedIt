# PlantedIt
A web app to find the best plants for starting your garden based on your location, weather data, and soil hardiness

## Resources

### API Fetching

- [Open Meteo](https://open-meteo.com/en/docs): Weather and location data
- [Perenual](https://perenual.com/docs/api): Plant encyclopedia
- [GBIF API](https://techdocs.gbif.org/en/openapi/)
- [What's My Zone](https://whatsmy.zone/api.html): USDA Plant Hardiness Zones
- [OpenStreetMap](https://wiki.openstreetmap.org/wiki/API): For location geocoding

### User Interface

- [Leaflet](https://github.com/Leaflet/Leaflet): Mapping software for web apps

### Tech Stack

- [NextJS](https://nextjs.org/): Can bind third-party APIs into local cached data to limit API load
- [TailWind CSS](https://tailwindcss.com/): CSS framework
