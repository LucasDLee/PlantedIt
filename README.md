# PlantedIt
A web app to find the best plants for starting your garden based on your location, weather data, and soil hardiness.

This was built with Next.js and Tailwind for server-side rendering to protect the API keys and custom components.

AI was only used to give advice on the tech stack, and troubleshoot and diagnose bugs.

## Resources

### API Fetching

- [Open Meteo](https://open-meteo.com/en/docs): Weather and location data
- [Plant Solve](https://www.plantsolve.com/): Plant encyclopedia
- [GBIF API](https://techdocs.gbif.org/en/openapi/)
- [Coords Zone](https://coords.zone/): USDA Plant Hardiness Zones
- [OpenStreetMap Nominatim](https://nominatim.org/release-docs/develop/api/Overview/): For location geocoding

### User Interface

- [Leaflet](https://github.com/Leaflet/Leaflet): Mapping software for web apps

### Tech Stack

- [NextJS](https://nextjs.org/): Can bind third-party APIs into local cached data to limit API load
- [Tailwind CSS](https://tailwindcss.com/): CSS framework

### Miscellaneous

- [Circle Flags](https://github.com/HatScripts/circle-flags): Country flags
